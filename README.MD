# 🎓 Smart Campus - Django

College Management System - Attendance, Notices, Timetable.

## Features
- Student Dashboard
- Attendance System
- Notice Board
- Timetable Management
- Faculty Panel
- Login / Register

## Tech Stack
- Python
- Django
- SQLite
- HTML, CSS, Bootstrap

## How to Run
pip install -r requirements.txt
python manage.py runserver
Open - http://127.0.0.1:8000
